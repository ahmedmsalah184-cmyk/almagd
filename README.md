# مكتب المجد لملابس الأطفال: تطبيق بحث الموديلات

تطبيق ويب (PWA) بيتثبت على الأندرويد والآيفون من GitHub Pages ويشتغل أوفلاين.

## 1) الرفع على GitHub Pages
1. أنشئ Repository جديد على GitHub (مثلاً `majd-app`) وخليه Public.
2. ارفع كل محتويات المجلد ده في الـ repository (index.html و app.js و style.css و sw.js و manifest.webmanifest ومجلدي lib و icons).
3. من Settings > Pages: Source = Deploy from a branch، Branch = main، المجلد = / (root)، واضغط Save.
4. بعد دقيقة الرابط يكون: `https://اسم-حسابك.github.io/majd-app/`

## 2) التثبيت على الموبايل
- أندرويد (Chrome): افتح الرابط، القائمة ⋮ ثم "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية".
- آيفون (Safari): افتح الرابط، زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

## 3) تحديث البيانات (من الإعدادات)
- طريقة 1: "اختيار ملف إكسيل" واختار الشيت من الموبايل.
- طريقة 2: ارفع ملف اسمه `data.xlsx` في الـ repository (بيستبدل القديم)، وفي التطبيق اضغط "تحديث من data.xlsx".
- الأعمدة: اسم المصنع، رقم الموديل، السعر (من الصف الأول، أو بالترتيب A و B و C).

## 4) تغيير الأيقونة
```
pip install pillow
python3 make_icons.py logo-original.jpg
```
بيعمل الأيقونات في مجلد icons/ بشكل ثلاثي الأبعاد. بعد ما ترفعها غيّر رقم VERSION في sw.js (مثلاً majd-v2) عشان الموبايل يحدّث.

## 5) أي تعديل في الكود
غيّر `VERSION` في sw.js كل مرة، وبعدها من الإعدادات اضغط "تحديث نسخة التطبيق".

## ملف APK (اختياري)
لو عايز ملف APK حقيقي: افتح pwabuilder.com، حط رابط GitHub Pages، واختار Android.
